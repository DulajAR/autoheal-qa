
# AutoHeal QA

Enterprise AI-Powered Self-Healing Test Automation Framework.

## Overview

AutoHeal QA is a professional test automation
framework using Playwright, TypeScript and Hybrid AI.

## Planned Features

- Cross-browser test automation
- Page Object Model architecture
- AI-powered self-healing locators
- Local and cloud AI support
- Automated test reporting
- CI/CD integration
- Multi-project testing

## Technology Stack

- Playwright
- TypeScript
- Node.js
- NestJS (planned)
- Next.js (planned)
- PostgreSQL (planned)
- Ollama / Cloud AI (planned)

## Development Status

Phase 1 - Playwright Automation Core

## Installation

```bash
npm install
npx playwright install chromium
```
